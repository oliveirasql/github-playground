# Páginas Estáticas no GitHub

Uma página estática é uma página da internet cujo conteúdo é apresentado de forma previamente definida. Ela normalmente utiliza tecnologias como HTML, CSS e JavaScript para criar a estrutura, o visual e algumas funcionalidades da página.

Diferentemente de aplicações dinâmicas, uma página estática não precisa gerar o conteúdo de forma diferente a cada acesso utilizando um servidor ou banco de dados.

## GitHub Pages

O GitHub oferece o recurso chamado **GitHub Pages**, que permite publicar páginas estáticas diretamente a partir de um repositório.

Com o GitHub Pages, é possível transformar arquivos de um projeto em um site acessível pela internet.

## Como criar uma página estática

Para criar uma página estática utilizando o GitHub, podemos seguir algumas etapas:

1. Criar um repositório no GitHub.
2. Criar os arquivos da página, como `index.html` e arquivos CSS.
3. Enviar os arquivos para o repositório utilizando o Git.
4. Configurar o GitHub Pages.
5. Acessar o endereço gerado pelo GitHub para visualizar a página.

## Exemplo de estrutura

Um projeto simples pode possuir a seguinte estrutura:

```text
meu-site/
├── index.html
├── style.css
└── imagens/
```

O arquivo `index.html` contém a estrutura da página, enquanto o arquivo `style.css` pode ser utilizado para definir sua aparência.

## Vantagens

O GitHub Pages apresenta algumas vantagens:

* Permite publicar páginas gratuitamente;
* Facilita o compartilhamento de projetos;
* Possibilita criar portfólios;
* É útil para projetos de estudo;
* Permite publicar documentação de projetos;
* Possui integração com repositórios do GitHub.

## Conclusão

As páginas estáticas são uma forma simples de criar e publicar sites. O GitHub Pages facilita esse processo ao permitir que arquivos armazenados em um repositório sejam disponibilizados como uma página na internet.

Esse recurso é bastante útil para estudantes e desenvolvedores que desejam praticar desenvolvimento web, criar portfólios ou publicar documentação de seus projetos.
