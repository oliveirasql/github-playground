# Aula 3 - Estruturas de Decisão

## O que são estruturas de decisão?

Estruturas de decisão são utilizadas na programação para permitir que um programa tome decisões de acordo com determinadas condições.

Elas verificam se uma condição é verdadeira ou falsa e, dependendo do resultado, executam diferentes comandos.

As principais estruturas de decisão são:

- `if`
- `else`
- `elif`

## Estrutura if

O `if` significa "se". Ele executa um determinado bloco de código quando uma condição é verdadeira.

Exemplo:

```python
idade = 18

if idade >= 18:
    print("Pessoa maior de idade")
