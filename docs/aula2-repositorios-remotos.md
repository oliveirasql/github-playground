Repositórios Remotos

Um repositório remoto é uma versão de um projeto Git armazenada em um servidor externo, permitindo o 
compartilhamento e sincronização dos arquivos.

Um exemplo de plataforma utilizada para hospedar repositórios remotos é o GitHub.
Funcionamento

O desenvolvedor trabalha em um repositório local e envia suas alterações para o repositório remoto 
utilizando comandos Git.

Principais comandos:

- `git add`  
Adiciona arquivos para serem preparados para o commit.

- `git commit`  
Registra as alterações no histórico do projeto.

- `git push`  
Envia os commits do repositório local para o repositório remoto.

- `git pull`  
Baixa alterações existentes no repositório remoto.

Os repositórios remotos facilitam o trabalho em equipe, controle de versões e armazenamento seguro dos projetos.
