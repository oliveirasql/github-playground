Conceitos de Frontend

Frontend é a parte de uma aplicação responsável pela interação direta com o usuário.

É tudo aquilo que o usuário visualiza e utiliza em um site ou sistema, como páginas, botões, menus e formulários.

Principais tecnologias

 HTML

Responsável pela estrutura das páginas web.

 CSS

Responsável pela aparência e estilização dos elementos.

 JavaScript

Responsável pela interação e comportamento dinâmico das páginas.

Frameworks Frontend

Alguns frameworks utilizados no desenvolvimento frontend são:

- React
- Angular
- Vue.js

O desenvolvimento frontend busca criar interfaces eficientes, responsivas e fáceis de utilizar pelos usuários.
