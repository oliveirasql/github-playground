# Estruturas de Repetição

As estruturas de repetição são utilizadas na lógica de programação para executar um determinado bloco de código várias vezes, de acordo com uma condição ou quantidade definida.

Elas ajudam a evitar a repetição desnecessária de comandos e tornam os programas mais organizados e eficientes.

## Principais estruturas de repetição

### For

A estrutura `for` é utilizada principalmente quando sabemos a quantidade de vezes que uma determinada ação deverá ser executada.

Exemplo:

```text
para cada número de 1 até 5:
    mostrar o número
```

Nesse caso, o programa executará o comando cinco vezes.

### While

A estrutura `while` executa um bloco de código enquanto uma determinada condição for verdadeira.

Exemplo:

```text
enquanto o número for menor que 5:
    mostrar o número
    aumentar o número em 1
```

O programa continuará executando enquanto a condição estabelecida for verdadeira.

### Do While

A estrutura `do while` é semelhante ao `while`, porém o bloco de código é executado pelo menos uma vez antes que a condição seja verificada.

## Importância das estruturas de repetição

As estruturas de repetição são importantes porque permitem automatizar tarefas que precisam ser realizadas várias vezes.

Elas são utilizadas em diversas situações, como:

* Percorrer listas e conjuntos de dados;
* Realizar cálculos repetitivos;
* Processar informações;
* Criar menus e sistemas interativos;
* Executar tarefas até que uma determinada condição seja atingida.

## Conclusão

As estruturas de repetição são fundamentais para a lógica de programação. O uso correto de `for`, `while` e outras estruturas permite criar programas mais organizados, eficientes e capazes de executar tarefas repetitivas de maneira automática.
